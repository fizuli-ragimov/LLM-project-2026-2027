# LLM-project-2026-2027
Хотим сделать LLM-систему для аналитики по структурированным и неструктурированным корпоративным данным.
Идея в том, что пользователь задаёт вопрос на естественном языке, а система сама определяет, какие источники данных и инструменты нужны для ответа. Например, она может обратиться к SQL-базе за числовыми данными, найти нужную информацию во внутренних документах, получить дополнительные данные через API или выполнить необходимые вычисления.
Для сложных запросов система разбивает задачу на несколько шагов, отдельно получает информацию из разных источников, сохраняет найденные факты вместе с их источниками, проверяет численные и фактические утверждения и только после этого формирует итоговый ответ со ссылками на использованные данные и документы.
Также планируем сравнивать разные стратегии поиска информации, подходы к Text-to-SQL и исследовать баланс между качеством ответа, временем работы системы и стоимостью её использования.
Для оценки качества хотим собрать собственный набор тестовых запросов разных типов: вопросы, требующие только SQL; вопросы, требующие поиска по документам; и сложные вопросы, для ответа на которые необходимо выполнить несколько шагов и объединить информацию из разных источников.
