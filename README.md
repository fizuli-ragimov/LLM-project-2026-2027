# LLM-project-2026-2027
Хотим сделать LLM-систему для аналитики по структурированным и неструктурированным корпоративным данным.
Идея в том, что пользователь задаёт вопрос на естественном языке, а система сама определяет, какие источники данных и инструменты нужны для ответа. Например, она может обратиться к SQL-базе за числовыми данными, найти нужную информацию во внутренних документах, получить дополнительные данные через API или выполнить необходимые вычисления.
Для сложных запросов система разбивает задачу на несколько шагов, отдельно получает информацию из разных источников, сохраняет найденные факты вместе с их источниками, проверяет численные и фактические утверждения и только после этого формирует итоговый ответ со ссылками на использованные данные и документы.
Также планируем сравнивать разные стратегии поиска информации, подходы к Text-to-SQL и исследовать баланс между качеством ответа, временем работы системы и стоимостью её использования.
Для оценки качества хотим собрать собственный набор тестовых запросов разных типов: вопросы, требующие только SQL; вопросы, требующие поиска по документам; и сложные вопросы, для ответа на которые необходимо выполнить несколько шагов и объединить информацию из разных источников.

## Локальный прогон КТ3

Нужен Python 3.10 или новее. Зависимости устанавливаются из корня репозитория:

```powershell
python -m pip install -r requirements.txt
```

### Бесплатный локальный прогон

```powershell
python -B -X utf8 -m kt3.run --output kt3/results_local.json
```

Команда трижды запускает детерминированный baseline и многошаговую систему на 45 видимых вопросах, проверяет шесть сценариев и записывает метрики вместе с трассами. Прогон работает на синтетическом корпусе без внешних сервисов. Отдельное имя `results_local.json` не позволяет случайно перезаписать итоговый отчёт КТ3.

Согласованность замороженного набора проверяется командой:

```powershell
python -B -X utf8 eval/validate_eval.py
```

### Полный прогон с LLM baseline

Ключ OpenAI передаётся только через переменную окружения. Для временной установки ключа в текущем окне PowerShell:

```powershell
$secureOpenAIKey = Read-Host "OPENAI_API_KEY" -AsSecureString
$env:OPENAI_API_KEY = [System.Net.NetworkCredential]::new("", $secureOpenAIKey).Password
Remove-Variable secureOpenAIKey
```

Полный прогон выполняется командой:

```powershell
python -B -X utf8 -m kt3.run `
  --output kt3/results.json `
  --repeats 3 `
  --include-llm `
  --llm-repeats 3
```

Команда добавляет 135 платных вызовов `gpt-6.2-sol` и перезаписывает итоговый отчёт. После прогона ключ удаляется из текущего окна:

```powershell
Remove-Item Env:OPENAI_API_KEY
```

Ключ не записывается в репозиторий или отчёт. Текущий [results.json](kt3/results.json) уже содержит сохранённый полный прогон трёх режимов.

Архитектура и измерения приведены в [дизайн-доке](design-doc.md).
