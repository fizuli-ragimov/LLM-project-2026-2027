# Релиз 1.2

## Основные изменения

Добавлены пользовательские поля для задач: текст, число, дата, список и флажок. Поля можно использовать в фильтрах и представлениях проекта.

## Доступность

Пользовательские поля доступны на тарифах Pro и Enterprise. На Pro разрешено до двадцати полей на проект, на Enterprise число полей не ограничено.

## Известные ограничения

Значения пользовательских полей пока не включаются в глобальный поиск. Изменение типа поля после добавления данных недоступно.
