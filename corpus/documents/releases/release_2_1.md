# Релиз 2.1

## Основные изменения

Для Enterprise обновлены модель ролей, аудит действий и управление политиками доступа. Добавлены шаблоны ролей, обязательное подтверждение критичных изменений и расширенный экспорт журнала аудита.

## Миграция

Существующие роли продолжают работать до подтверждения администратором. После миграции права пересчитываются для каждого рабочего пространства. Операция может занять до 24 часов.

## Известные ограничения

При сложной структуре собственных ролей администратору может потребоваться ручная проверка правил. Релиз совпадает по времени с изменениями показателей Enterprise, но документ не подтверждает причинную связь.
