# Условия тарифа Pro

## Стоимость

Стоимость составляет 800 рублей за одну лицензию в месяц. При годовой оплате действует скидка 15%. Максимальное число лицензий равно ста.

## Возможности

Тариф включает неограниченное число проектов, пользовательские поля, расширенные отчёты, календарь, зависимости задач, API и до пятидесяти правил автоматизации на проект. Добавлены интеграции с корпоративными мессенджерами.

## Ограничения

История и журнал действий хранятся 180 дней. SSO и SCIM не входят в тариф. Частота запросов к API ограничена 600 запросами в минуту на компанию.

## Поддержка

Доступна приоритетная поддержка через чат и электронную почту. SLA по доступности и времени реакции не предоставляется.
